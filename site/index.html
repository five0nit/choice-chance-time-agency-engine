The short version

CCT helps an agent decide what deserves a next step. Persistent goals give it direction. History gives it context. Explicit authority limits the effect. Verification tells it what actually happened.

01 / The idea

Three ingredients.
Not a claim of consciousness.

C × C × T

Choice–Chance–Time is an engineering model of operational agency: alternatives, bounded exploration, and continuity.

Read the complete model ↗
C₁Choice
Compare real alternatives, including doing nothing. Keep the reasons and rejected branches inspectable.Without it: a forced response.
C₂Chance
Explore within the allowed set using recorded seeds. Blockers apply before probability, never after.Without it: a policy that can stay frozen.
TTime
Carry goals, commitments, evidence and outcomes forward. Let consequences inform the next choice.Without it: another stateless reaction.

02 / The mechanism

From a signal
to a verified next step.

The model can propose. The host grants authority. The engine keeps the decision and its consequences connected.

  1. 01

    Observe

    Bring in structured observations from configured sources.

  2. 02

    Remember

    Relate the signal to goals, commitments and history.

  3. 03

    Filter

    Remove blocked options. Preserve NO_OP.

  4. 04

    Decide

    Score allowed alternatives; record bounded exploration.

  5. 05

    Respond

    Take an authorized step, wait, or surface a question.

  6. 06

    Verify

    Check the actual effect. Keep receipts, not just claims.

  7. 07

    Learn

    Update reliability from outcomes, within the same authority.

03 / Restraint is part of agency

Doing nothing
is a decision.

An agent that notices everything should not interrupt about everything. Useful initiative needs a way to stay quiet.

“Be proactive” is an intention.
These are mechanisms.

NO_OP / WAIT
Deferring is a first-class outcome—not a failed attempt to find work.
Cooldown
A relevant idea does not need to be repeated at every wake.
Deduplication
Unchanged state and already-claimed work should not produce another effect.
Caps
Bounded emissions and action budgets constrain throughput even when work looks useful.

04 / Read the boundary

Intention
is not permission.

A proposed goal, an interested reply, or a successful past run does not authorize a new kind of effect.

A / Core local executor

Narrow by construction.

The autonomous filesystem executor creates new text files beneath a pinned workspace root, with bounds and independent verification. It does not overwrite existing files.

Shell, network, publication, credential access and other broad effects are not part of that executor. More proven throughput does not turn it into a general-purpose command runner.

Authority model ↗

B / Explicit optional integrations

Separate gates. Separate setup.

Operator adapters and standing autonomy can enable configured effects only through host-owned registrations, scoped leases or exact tickets, and their own verification.

The optional Firebase owner control plane adds authenticated remote coordination through a local sidecar. Canonical authority stays local; this education page connects to none of it.

Principal & capability gates ↗
Know what this does not cover.

CCT does not sandbox the surrounding agent process or automatically mediate all its other tools. Hash-chained history is an audit mechanism, not protection against a fully compromised host. This is alpha software, not a production security guarantee.
