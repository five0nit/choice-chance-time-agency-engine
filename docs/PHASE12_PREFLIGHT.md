## Required invariants

- Opportunity presentation is not execution authorization.
- `INTERESTED` means operator interest only; it never grants a lease, registers a capability, or attaches an executable plan.
- Self/model proposals may be presented but remain non-executable.
- Only host/operator opportunities may cross existing CCT executor gates.
- Every message uses existing global cooldown, daily cap, semantic digest, and at-most-once emission guards.
- No raw conversation, hidden chain-of-thought, workspace file content, credentials, or producer instructions enter opportunity receipts.
- Idle ticks remain model-free and silent.
- Restart, crash-window, and concurrent scheduler behavior remain deterministic.
- The live Telegram gateway is not restarted without Mike's explicit approval.
