# Public verification boundary

Private deployment logs, account identifiers, service paths and historical acceptance records are intentionally omitted from the public distribution. They do not establish acceptance for a new installation.

See [the verification guide](VERIFICATION.md) for reproducible checks and [the public release record](../PUBLIC_RELEASE.md) for this release. Optional owner integrations require their own identity configuration, sandbox prerequisites and fresh verification. This source update does not activate or replace a live cloud or agent service.
